Meet msging

A modern real-time messaging app. Direct messages, group chats, email verification, and a sleek dark UI — built for privacy and speed.

View on GitHub Learn More

Features

Everything you need in a messaging app, nothing you don't.

✉

Direct Messaging

One-on-one conversations with real-time delivery. See who's online, get instant notifications, and never miss a message.

👥

Group Chats

Create groups with multiple members. Give them a name, add people, and start chatting together instantly.

🔒

Email Verification

Every account is verified via email. No bots, no spam — just real people having real conversations.

🌑

Dark Theme

A carefully crafted dark UI with purple accents. Easy on the eyes, day or night.

⚡

Real-Time Sync

Messages appear instantly across all devices. Powered by Firebase with sub-second delivery.

🔐

Secure by Design

Firestore security rules ensure only you can access your messages. Data is encrypted in transit and at rest.
